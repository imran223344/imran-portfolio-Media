# Imran Masood — Professional CV Website

Files:
- index.html — complete responsive website
- assets/profile-photo.jpg — profile image extracted from supplied CV
- assets/imran-media-cv.png — full CV image
- Imran_Masood_Media_CV.pdf — downloadable CV

GitHub Pages:
1. Create/open your repository.
2. Upload all files and keep the `assets` folder.
3. In Settings → Pages, select Deploy from a branch → main → /root.
4. Open the generated GitHub Pages URL.

The site is static, so it works on GitHub Pages, Netlify, and similar hosting.
